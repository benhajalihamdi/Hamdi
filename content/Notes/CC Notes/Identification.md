- **Intrusion Detection System (IDS):** A monitoring system that detects suspicious activities and generates alerts. It is "passive," meaning it identifies threats but does not block them automatically.
- **Network Intrusion Detection System (NIDS):** An IDS that monitors and analyzes network traffic at strategic points to identify threats directed at the entire network.
- **Host-based Intrusion Detection System (HIDS):** An IDS installed on a specific device (host) that monitors internal system calls, log files, and application activity for that specific machine.
