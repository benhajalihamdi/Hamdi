- **Antivirus:** Software designed to detect, quarantine, and remove malicious software. Modern versions use both signature-based detection and "heuristics" to find new threats based on behavior.
- **Scans:** Regular, automated checks of systems or network traffic (like vulnerability scans) to find weak points, unpatched software, or existing infections before they are exploited.
- **Firewalls:** A security barrier that controls incoming and outgoing network traffic based on predetermined security rules. It acts as the first line of defense between a trusted and untrusted network.
- **Intrusion Prevention System (IPS):** An "active" security tool that monitors network traffic like an IDS but has the power to automatically take action, such as dropping malicious packets or blocking an IP address, to stop an attack in progress.
