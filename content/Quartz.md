I first heard about Quartz from [Ewan Pedersen](https://ewan.my/) and inspired me to create my own since at the time I have already dabbled a bit in using obsidian for note taking and documenting.

A key concept about this website that it hosts already written notes from my Obsidian Vault to the web. Quartz simply converts .md files to .http and .css files and creates this static website, it also adds a graph for all the nodes and node connections between the files, from other functionalities.

check [Quartz](https://quartz.jzhao.xyz/) if you want to create your own!
