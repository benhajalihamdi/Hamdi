the formula for calculating the loss of training data using the MSE formula is:

$$L =\sum_{c=0}^{n-1}(a_c-y_c)^2$$

where a $a_c$ is the value of the prediction for a coordinate and $y_c$ is the correct value for that coordinate  $n$ is the number of neurons in the layer.

Difference between Cost and Loss, basically the same thing: Cost represent the cost for the entire dataset where loss represent the cost for one data example. Cost the average of all the Losses
