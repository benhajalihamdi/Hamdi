A computer network is a digital telecommunication network which allows *nodes* to share ressources.
## End Points

A client is a device that accesses a service made available by a server.
A server is a device that provides functions or services to a client.

a server or a client can be any machines basically, because the utility of the machine determines if it's a server or a client not an inherent thing of the machine.
## Switches 
(Cisco Catalyst)
switches are used to forward traffic within a LAN(local area network), per example catalyst switches.

- they have many network interfaces/ports for end hosts to connect to usually 24+
- provide connectivity to hosts *within* the same *LAN*.
- do not provide connectivity *between LANs* (over the internet)
## Router

Routers (CISCO ISR)
compared to a switch a router has less network interfaces than switches
they also:
- provide connectivity *between* LANs
Routers can also provide basic security features
